# 🧪 Validación — Integración de Gallery-DL GUI

## Criterios de Aceptación
1. [x] El ítem **Gallery-DL** aparece en `HERRAMIENTAS` en la barra lateral con su icono `layers`.
2. [x] Al ingresar a la vista, se despliega el hub con diseño homogéneo para tema claro y oscuro (`#059669` / `#0284c7`).
3. [x] El selector de estructura de descarga permite elegir opciones con dropdown customizado sin bordes punteados.
4. [x] El envío de una URL interactúa con el `InterceptionServer` o lanza `GalleryDL-GUI.exe`.
5. [x] Los botones de sinergia navegan a Imágenes, Convertidor y abren la carpeta en el Explorador.
6. [x] Cero errores de compilación en TypeScript (`bun run check` exitoso) y Rust (`cargo check` exitoso).
