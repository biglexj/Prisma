# Preparación local de Prisma 2.0.0

Revisar los cambios acumulados, comprobar compilación y pruebas, inspeccionar la aplicación instalada y preparar un instalador local mediante el script oficial en modo LocalOnly. Conservar los perfiles y la instalación actual del usuario. No publicar, hacer push, crear tags ni sincronizar metadata de Aurora.

La distribución vigente utiliza el instalador EXE de Inno Setup definido por el proyecto, que sustituye el empaquetado anterior. No se genera un MSI diferente durante esta consolidación.
