# Aviso de atribución

Este proyecto utiliza la licencia MIT estándar. La licencia exige conservar el aviso de copyright y el texto de la licencia en todas las copias o partes sustanciales del software.

Además, se solicita que cualquier redistribución o proyecto derivado:

- Mencione claramente el nombre del proyecto original.
- Reconozca a `biglexj` como autor del trabajo original.
- No presente el proyecto original completo como creación exclusiva de otra persona u organización.

Este aviso expresa una solicitud de atribución visible y no modifica ni añade restricciones a la licencia MIT. Si se necesita convertir estas condiciones en obligaciones contractuales adicionales, debe utilizarse una licencia personalizada revisada legalmente y no denominarse simplemente «MIT».
